    О сервисе
    RawerGit превращает обычные ссылки GitHub в прямые raw-ссылки на исходный код. Вставляете URL — получаете чистый код и готовую ссылку для встраивания.

    Получить raw-версию файла

    Вставьте ссылку на GitHub-файл — получите прямой URL и исходный код.

    Поддерживаются ссылки вида github.com/.../blob/... и github.com/.../raw/...
