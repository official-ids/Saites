    API Reference

    Полная документация внутреннего REST API платформы Oris. Описывает все эндпоинты, используемые фронтендом для взаимодействия с серверной логикой.

    API не предназначен для публичного использования
    Данный API является внутренним и используется исключительно фронтендом платформы Oris. Он не имеет публичной документации, SLA, версионирования или обратной совместимости. Сторонним разработчикам не рекомендуется использовать эти эндпоинты — они могут измениться в любой момент без предупреждения. Интеграции с внешними сервисами осуществляются через официальные механизмы (Telegram Bot API, GitHub API).
