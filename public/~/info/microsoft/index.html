О компании Microsoft

Американская транснациональная корпорация, один из мировых лидеров в области программного обеспечения, облачных вычислений и игровых технологий.

Microsoft Corporation — одна из крупнейших и наиболее влиятельных технологических компаний в мире. Основана 4 апреля 1975 года Биллом Гейтсом и Полом Алленом в Альбукерке, штат Нью-Мексико. Сегодня штаб-квартира компании расположена в Редмонде, штат Вашингтон.

Microsoft начинала как разработчик интерпретаторов языка BASIC для альтернативных компьютеров, а сегодня её продукты используются миллиардами людей по всему миру: от операционной системы Windows до облачной платформы Azure, от пакета Office до игровой консоли Xbox.

Ключевые факты

Глобальное присутствие

Офисы в более чем 190 странах мира. Продукты компании используются на миллиардах устройств ежедневно.

Лидер рынка

Одна из пяти крупнейших tech-компаний мира (наряду с Apple, Google, Amazon, Meta). Рыночная капитализация превышает $3 трлн.

Диверсификация

Бизнес охватывает ОС, офисное ПО, облака, игры, поисковые системы, социальные сети, ИИ и профессиональные сети.

Инновации

Значительные инвестиции в исследования: более $30 млрд в R&D ежегодно. Лидер в области ИИ после инвестиций в OpenAI.

Важно понимать Microsoft — это не только Windows. Сегодня большая часть выручки компании поступает от облачных сервисов (Azure), бизнес-приложений (Microsoft 365, LinkedIn) и игрового подразделения (Xbox). Windows — лишь один из многих сегментов бизнеса.

История Microsoft

От небольшого стартапа до одной из самых дорогих компаний в мире. Путь длиной в полвека.
1975

Основание компании

Билл Гейтс и Пол Аллен основывают Microsoft в Альбукерке, Нью-Мексико. Первый продукт — интерпретатор Altair BASIC для компьютера Altair 8800.

1980

Сделка с IBM

Microsoft покупает операционную систему QDOS у Seattle Computer Products, адаптирует её и поставляет IBM как PC-DOS. Это становится поворотным моментом в истории компании.

1981

Выход MS-DOS

IBM PC с MS-DOS выходит на рынок. Microsoft сохраняет права на продажу MS-DOS другим производителям, что становится основой будущего доминирования.

1985

Первая версия Windows

Выходит Windows 1.0 — графическая оболочка для MS-DOS. Начинается эра графических интерфейсов от Microsoft.

1989

Появление Office

Выходит Microsoft Office — пакет, объединяющий Word, Excel и PowerPoint. Он станет стандартом для офисной работы во всём мире.

1995

Windows 95 и Internet Explorer

Революционный релиз Windows 95 с меню Пуск. Одновременно выпущен браузер Internet Explorer, начинающий "браузерные войны" с Netscape.

2001

Windows XP и Xbox

Выходит Windows XP — одна из самых успешных ОС в истории. В том же году запущена игровая консоль Xbox, выводящая Microsoft на рынок консолей.

2005–2010

Эра Vista, 7 и Bing

Неудачный запуск Windows Vista, исправленный успешной Windows 7. Запуск поисковой системы Bing в 2009 году как конкурент Google.

2014

Сатья Наделла — новый CEO

Сатья Наделла становится третьим CEO в истории Microsoft. Начинается трансформация компании в сторону облачных технологий и открытого кода.

2016

Покупка LinkedIn

Microsoft приобретает профессиональную социальную сеть LinkedIn за $26,2 млрд — крупнейшее приобретение в истории компании на тот момент.

2018

Покупка GitHub

Приобретение GitHub за $7,5 млрд. Microsoft становится крупнейшим участником open-source сообщества, что было немыслимо в 90-е.

2023

Эра ИИ и инвестиции в OpenAI

Microsoft инвестирует $13 млрд в OpenAI и интегрирует GPT-4 в свои продукты: Bing, Office, GitHub Copilot. Начинается новая эра в истории компании.

2023–2026

Лидер облаков и ИИ

Microsoft Azure конкурирует с AWS за лидерство в облаках. Copilot интегрируется во все продукты. Рыночная капитализация превышает $3 трлн.

Структура компании

Microsoft — это сложная корпоративная структура с несколькими ключевыми бизнес-сегментами.

Руководство

Сатья Наделла

CEO с 2014 года. Превратил Microsoft из компании, ориентированной на Windows, в лидера облачных технологий и ИИ.

Совет директоров

Возглавляет Джон Томпсон (председатель). Включает независимых директоров и представителей крупных инвесторов.

Бизнес-сегменты

Microsoft отчитывается по трём основным сегментам:

Productivity and Business Processes

Microsoft 365 (Office), LinkedIn, Dynamics 365. Корпоративные решения для продуктивности и бизнес-процессов.

Intelligent Cloud

Azure, серверные продукты, корпоративные сервисы. Самый быстрорастущий сегмент, приносящий значительную часть выручки.

More Personal Computing

Windows, игровое подразделение (Xbox), поисковая система Bing, устройства Surface, реклама.

Исследования (Microsoft Research)

Одно из крупнейших в мире исследовательских подразделений в области компьютерных наук. Лаборатории по всему миру.

Трансформация бизнеса При Сатье Наделле Microsoft прошла трансформацию от "Windows-центричной" компании к "cloud-first, AI-first". Сегодня облачные сервисы приносят больше выручки, чем все продукты Windows вместе взятые.

Windows

Самый известный продукт Microsoft. Операционная система, которая стоит на большинстве персональных компьютеров в мире.

Основные версии

Windows 95 / 98 / XP

Классические версии, сформировавшие современный вид ПК. Windows XP стала одной из самых успешных ОС в истории.

Windows 7

Вышла в 2009 году, считается одной из лучших версий Windows. Любима пользователями за стабильность и удобство.

Windows 10

Вышла в 2015 году. Возвращение меню Пуск, универсальные приложения, интеграция с облаком. Самая распространённая ОС сегодня.

Windows 11

Вышла в 2021 году. Обновлённый дизайн, центрированная панель задач, виджеты, интеграция с Teams и ИИ.

Ключевые особенности современных Windows

  • Microsoft Store — магазин приложений с проверенным контентом
  • Windows Hello — биометрическая аутентификация (лицо, отпечаток)
  • DirectX 12 — современный графический API для игр
  • WSL (Windows Subsystem for Linux) — запуск Linux-приложений в Windows
  • Copilot — ИИ-помощник, встроенный в систему
  • Virtual Desktops — виртуальные рабочие столы
  • Snap Layouts — удобное размещение окон
  • BitLocker — шифрование дисков
Прекращение поддержки Windows 10 14 октября 2025 года Microsoft прекратила бесплатную поддержку Windows 10. Пользователям рекомендуется перейти на Windows 11 или приобрести расширенную поддержку.

Microsoft 365

Ранее известный как Office 365 — подписочный пакет офисных приложений и облачных сервисов Microsoft.

Основные приложения

Word

Текстовый редактор. Стандарт для создания документов. Совместная работа в реальном времени, ИИ-функции.

Excel

Табличный процессор. Мощные формулы, сводные таблицы, визуализация данных. Незаменим для аналитики.

PowerPoint

Создание презентаций. Тысячи шаблонов, анимации, переходы, интеграция с ИИ для дизайна.

Outlook

Почтовый клиент и органайзер. Email, календарь, контакты, задачи. Интеграция с Exchange и облаком.

OneNote

Цифровой блокнот для заметок. Рукописный ввод, организация в блокноты, синхронизация между устройствами.

Access

Система управления базами данных для настольных решений. Только в Windows-версии Office.

Варианты подписки

  • Microsoft 365 Family — до 6 пользователей, по 1 ТБ каждому, семейный доступ

Бизнес-подписки

  • Business Standard — настольные приложения + облачные сервисы
  • Business Premium — всё из Standard + расширенная безопасность
  • Apps for Business — только настольные приложения Office

Корпоративные подписки

  • Microsoft 365 E3 — полный набор приложений + безопасность + соответствие
  • Microsoft 365 E5 — максимальный уровень безопасности, аналитика, голосовые функции
  • Office 365 E1/E3/E5 — только облачные сервисы без настольных приложений
  • Microsoft 365 F3 — для линейных сотрудников

Azure и облачные технологии

Microsoft Azure — одна из крупнейших облачных платформ в мире, конкурирующая с Amazon Web Services.

Что такое Azure

Microsoft Azure — это облачная платформа, предоставляющая более 200 услуг: от виртуальных машин и хранилищ до ИИ, машинного обучения, Интернета вещей и блокчейна. Azure работает в более чем 60 регионах по всему миру.

Ключевые сервисы

Виртуальные машины

Windows и Linux серверы по требованию. Различные конфигурации для любых задач.

Базы данных

SQL Database, Cosmos DB, PostgreSQL, MySQL. Управляемые СУБД для любых сценариев.

Azure AI

Когнитивные сервисы: распознавание речи, изображений, перевод, ИИ-ассистенты.

Интернет вещей (IoT)

Платформа для подключения и управления миллиардами устройств IoT.

Позиция на рынке

Azure занимает второе место на рынке облачных инфраструктур (IaaS + PaaS) после Amazon Web Services. Доля Azure составляет около 25% рынка, AWS — около 31%. Google Cloud занимает третье место с долей около 11%.

Гибридное облако Уникальное преимущество Microsoft — возможность гибридных решений, сочетающих локальные серверы и облако. Azure Arc позволяет управлять инфраструктурой где угодно: в облаке, на границе сети или в дата-центре.

Xbox и игровое подразделение

Microsoft — один из крупнейших игроков игровой индустрии с брендом Xbox, студиями и сервисом Game Pass.

Игровые консоли Xbox

Xbox Original (2001)

Первая консоль Microsoft. Вышла с игрой Halo: Combat Evolved, ставшей культовой. Конкурировала с PlayStation 2.

Xbox 360 (2005)

Одна из самых успешных консолей. Xbox Live, достижения, Kinect. Конкуренция с PlayStation 3 и Wii.

Xbox One (2013)

Третье поколение. Интеграция с ТВ, Kinect 2.0. Менее успешна, чем 360, из-за высокой цены и ограничений.

Xbox Series X/S (2020)

Текущее поколение. Series X — мощная консоль для 4K, Series S — бюджетная для 1440p. SSD, Quick Resume.

Xbox Game Pass

Xbox Game Pass — подписочный сервис, дающий доступ к сотням игр за ежемесячную плату. Часто называется "Netflix для игр". Включает игры от Microsoft в день релиза.

  • Game Pass Core — базовый уровень с онлайн-мультиплеером и 25 играми
  • Game Pass Standard — доступ к библиотеке игр без EA Play
  • Game Pass Ultimate — все игры + EA Play + облачный гейминг + perks
  • PC Game Pass — библиотека игр для ПК

Игровые студии Microsoft

После приобретения ZeniMax Media (Bethesda) в 2021 году за $7,5 млрд и Activision Blizzard в 2023 году за $69 млрд, Microsoft стала обладать одной из крупнейших коллекций игровых студий в мире:

  • Xbox Game Studios — 343 Industries (Halo), Turn 10 (Forza), The Coalition (Gears), Playground Games (Forza Horizon, Fable)
  • Bethesda — id Software (Doom), Arkane (Dishonored, Prey), Tango Gameworks, MachineGames (Wolfenstein)
  • Activision Blizzard — Call of Duty, World of Warcraft, Diablo, Overwatch, Candy Crush
  • Obsidian Entertainment — Fallout: New Vegas, Pentiment, Avowed
  • inXile Entertainment — Wasteland 3
  • Ninja Theory — Hellblade, Senua's Saga
Покупка Activision Blizzard Сделка на $69 млрд стала крупнейшим приобретением в истории игровой индустрии. Она вызвала антимонопольные расследования в США, ЕС и Великобритании, но в итоге была одобрена с некоторыми условиями.

Искусственный интеллект

Microsoft — один из мировых лидеров в области ИИ, во многом благодаря стратегическому партнёрству с OpenAI.

Партнёрство с OpenAI

Microsoft начала инвестировать в OpenAI в 2019 году ($1 млрд), а в январе 2023 года объявила о расширении партнёрства с инвестициями в $13 млрд. Это сделало Microsoft основным бенефициаром технологий OpenAI и обеспечило эксклюзивный доступ к моделям GPT для своих продуктов.

ИИ-продукты Microsoft

Microsoft Copilot

ИИ-помощник, интегрированный в Windows, Microsoft 365, Edge, Bing. Помогает с текстом, кодом, анализом данных.

GitHub Copilot

ИИ-ассистент для разработчиков. Автодополнение кода в Visual Studio, VS Code и других IDE. Более 1 миллиона платных подписчиков.

Azure OpenAI Service

Корпоративный доступ к моделям GPT-4, DALL-E, Whisper через Azure. Для бизнеса с требованиями безопасности.

Bing Chat

ИИ-чат в поисковой системе Bing. Ответы на вопросы, генерация контента, анализ веб-страниц на базе GPT-4.

Microsoft Research и ИИ

Microsoft Research — одно из крупнейших в мире исследовательских подразделений в области ИИ. Лаборатории в Редмонде, Кембридже, Пекине и других городах работают над фундаментальными и прикладными задачами машинного обучения, компьютерного зрения, обработки естественного языка.

Стратегия "AI-first" Сатья Наделла провозгласил Microsoft "AI-first компанией". ИИ интегрируется во все продукты: от Windows и Office до Azure и Xbox. Это определяет стратегию компании на ближайшие годы.

Критика и противоречия

Как и любая крупная корпорация, Microsoft сталкивается с критикой по различным направлениям.

Историческая критика

Антимонопольный процесс 1998

США против Microsoft: обвинение в монополизации рынка браузеров через捆绑 Internet Explorer с Windows. Итог — мировое соглашение и ограничения.

Windows Vista (2007)

Провальный запуск: проблемы с производительностью, совместимостью, DRM. Подорвал репутацию Microsoft на несколько лет.

Отношение к open-source (90-е)

Балмер называл Linux "раковой опухолью". Сегодня Microsoft — один из крупнейших участников open-source (GitHub, VS Code, .NET).

Телеметрия Windows 10/11

Критика за сбор данных пользователей. Microsoft утверждает, что телеметрия анонимна и нужна для улучшения продуктов.

Современные вызовы

  • Антимонопольные расследования в ЕС — практика привязки Teams к Office вызвала претензии Еврокомиссии
  • Поглощение Activision Blizzard — критика за концентрацию игрового рынка
  • Массовые сокращения 2023-2024 — более 15 000 сотрудников уволено несмотря на рекордную прибыль
  • ИИ-этика — вопросы об ответственности за ИИ-решения, авторских правах на обучение моделей
  • Принудительные обновления Windows — критика за автоматическую установку обновлений без согласия пользователей
  • Политика подписок — переход от разовых покупок к подпискам вызывает недовольство части пользователей
Эволюция компании Microsoft значительно изменилась за последние 10 лет. Из компании, известной агрессивной конкуренцией и закрытостью, она превратилась в одного из главных сторонников open-source, облачных технологий и сотрудничества с конкурентами.

Частые вопросы

Ответы на самые популярные вопросы о Microsoft и её продуктах.
Кто основал Microsoft?

Microsoft основали Билл Гейтс (Bill Gates) и Пол Аллен (Paul Allen) 4 апреля 1975 года в Альбукерке, штат Нью-Мексико. Они были друзьями детства и вместе работали над программными проектами. Пол Аллен покинул компанию в 1983 году из-за болезни, но оставался крупным акционером до своей смерти в 2018 году.

Сколько сотрудников в Microsoft?

По состоянию на 2024-2025 годы в Microsoft работает более 220 000 сотрудников по всему миру. После покупки Activision Blizzard в 2023 году штат увеличился примерно на 12 000 человек. В 2023-2024 годах компания также провела массовые сокращения, затронувшие около 15 000 сотрудников.

Чем Microsoft отличается от Apple?

Основные различия: Microsoft фокусируется на программном обеспечении и облачных сервисах, Apple — на устройствах и экосистеме. Microsoft более открыта к сторонним платформам (Office есть на iOS и Android), Apple строит закрытую экосистему. Microsoft доминирует в корпоративном сегменте, Apple — в потребительском премиум-сегменте.

Почему Microsoft купила GitHub?

Приобретение GitHub в 2018 году за $7,5 млрд было частью стратегии Сатьи Наделлы по превращению Microsoft в лидера облачных технологий и open-source. GitHub — крупнейшая платформа для разработчиков с более чем 100 миллионами пользователей. Microsoft сохранила независимость GitHub и продолжает развивать его как открытую платформу.

Что такое Microsoft 365 и чем отличается от Office?

Microsoft 365 — это подписочная модель, включающая Office-приложения (Word, Excel, PowerPoint), облачные сервисы (OneDrive, Teams), регулярные обновления и дополнительные функции. Office — это разовая покупка только настольных приложений без облачных сервисов и обновлений. Microsoft 365 более выгоден при длительном использовании.

Windows 11 лучше Windows 10?

Windows 11 предлагает обновлённый дизайн, улучшенную производительность, новые функции (Snap Layouts, виджеты, интеграция с Teams). Однако у неё более высокие системные требования (нужен TPM 2.0, процессоры 8-го поколения и новее). Для современных ПК Windows 11 предпочтительнее, для старых — Windows 10 может работать стабильнее.

Что такое Xbox Game Pass?

Xbox Game Pass — подписочный сервис, дающий доступ к библиотеке из сотен игр за ежемесячную плату. Все игры Microsoft выходят в Game Pass в день релиза. Есть версии для консоли, ПК и Ultimate (обе платформы + облачный гейминг). Часто называют "Netflix для игр".

Что такое Copilot?

Copilot — это ИИ-помощник Microsoft, основанный на технологиях OpenAI (GPT-4). Интегрирован в Windows, Microsoft 365 (Word, Excel, PowerPoint, Outlook, Teams), Edge и Bing. Помогает с написанием текстов, анализом данных, созданием презентаций, программированием. Есть бесплатная и платная версии.

Что случилось с Windows Phone?

Windows Phone была попыткой Microsoft создать третью мобильную платформу после iOS и Android. Запущена в 2010 году, но не смогла завоевать рынок из-за малого количества приложений. В 2017 году разработка прекращена. Microsoft списала $7,6 млрд от покупки Nokia. Сегодня Microsoft фокусируется на мобильных приложениях для iOS и Android.

Как Microsoft относится к Linux?

Отношение кардинально изменилось. В 2000-х Стив Балмер называл Linux "раковой опухолью". При Сатье Наделле Microsoft стала одним из крупнейших участников open-source. Сегодня Microsoft поддерживает WSL (Windows Subsystem for Linux), активно развивает .NET на Linux, является топ-контрибьютором в Linux-ядро. "Microsoft loves Linux" — слова Наделлы.

Что такое Surface?

Surface — линейка устройств Microsoft: ноутбуки (Surface Laptop, Surface Pro), планшеты, ПК (Surface Studio), аксессуары. Surface служат эталонными устройствами для демонстрации возможностей Windows. Конкурируют с MacBook, iPad Pro и другими премиум-устройствами.

Платит ли Microsoft дивиденды?

Да, Microsoft платит дивиденды с 2003 года и регулярно их увеличивает. Это одна из "дивидендных аристократов" — компаний, увеличивающих выплаты более 25 лет подряд. Также компания активно выкупает собственные акции, возвращая акционерам десятки миллиардов долларов ежегодно.

Что будет с Microsoft в будущем?

Microsoft фокусируется на трёх направлениях: облачные технологии (Azure), искусственный интеллект (Copilot, OpenAI) и игровая индустрия (Xbox, Game Pass). Компания продолжает инвестировать в ИИ, квантовые вычисления, смешанную реальность (HoloLens) и устойчивое развитие. Ожидается дальнейший рост выручки и усиление позиций в корпоративном сегменте.

Можно ли использовать Office бесплатно?

Да, Microsoft предлагает бесплатные веб-версии Word, Excel, PowerPoint и OneNote через office.com. Они имеют ограниченный функционал по сравнению с платными версиями, но подходят для базовых задач. Также Office доступен бесплатно для студентов и преподавателей через учебные заведения.
