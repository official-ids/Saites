Возможности

Что умеет JSON Studio

Полный набор инструментов для работы с JSON-данными.

Редактор Monaco
Профессиональный редактор кода на базе Monaco (тот же, что в VS Code) с подсветкой синтаксиса, автодополнением и сворачиванием блоков.
Валидация JSON
Мгновенная проверка синтаксиса с точным указанием строки и столбца ошибки. Поддержка JSON Schema для структурной валидации.
Конвертация форматов
Преобразование между JSON, XML, YAML и CSV в обоих направлениях. Собственные парсеры без внешних зависимостей.
Форматирование
Автоматическое форматирование с настраиваемыми отступами (пробелы или табы), минификация и сортировка ключей по алфавиту.
Сравнение JSON
Визуальное сравнение двух JSON-документов с подсветкой добавленных, удалённых и изменённых элементов.
Инструменты кодирования
Base64, URL Encode/Decode, JSON Escape/Unescape, Unicode конвертер, генератор хешей (SHA-256).
Генераторы
Генерация UUID v4, timestamp'ов, случайных данных и JSON Schema по заданным полям.
Система файлов
Открытие, сохранение, закрепление файлов. История недавних файлов, автоматические бэкапы с восстановлением.
Интеграция с Windows
Ассоциация файлов .json, открытие через правый клик, нативные диалоги сохранения, кастомная title bar в стиле Windows 11.

01 Установка

Вариант А: Установщик (рекомендуется)

  1. Скачайте файл JSON Studio Setup 1.0.0.exe с этой страницы.
  2. Запустите установщик. При появлении запроса UAC нажмите «Да».
  3. Выберите папку установки (по умолчанию C:\Program Files\JSON Studio).
  4. Установщик автоматически:
    • Создаст ярлык на рабочем столе
    • Добавит запись в меню «Пуск»
    • Зарегистрирует ассоциацию файлов .json
    • Добавит пункт «Открыть с помощью JSON Studio» в контекстное меню
  5. Нажмите «Готово» и запустите приложение.

Вариант Б: Portable версия

  1. Скачайте файл JSON Studio 1.0.0.exe.
  2. Сохраните в любую папку (например, C:\Tools\JSONStudio\).
  3. Запустите двойным кликом — установка не требуется.
  4. Для открытия файлов перетаскивайте их на окно приложения.

Проверка установки

После установки щёлкните правой кнопкой мыши по любому .json файлу. В контекстном меню должен появиться пункт «Открыть с помощью JSON Studio».

02 Первый запуск

При первом запуске JSON Studio загрузит веб-интерфейс с серверов Oris Platform. Требуется подключение к интернету.

  • Приложение загрузит последнюю версию интерфейса автоматически
  • Настройки сохраняются локально в браузере (localStorage)
  • Файлы хранятся в памяти приложения до закрытия

Если интернет недоступен, вы увидите экран с ошибкой и кнопкой «Повторить».

04 Работа с файлами

Открытие файла

  • Через меню: Файл → Открыть (Ctrl+O)
  • Через проводник: правый клик по .json → «Открыть с помощью JSON Studio»
  • Drag & Drop: перетащите файл в окно приложения

Сохранение

  • Ctrl+S — сохранить в текущий файл
  • Ctrl+Shift+S — «Сохранить как...» с выбором пути
  • Автосохранение каждые 30 секунд (настраивается)

Закрепление файлов

Важные файлы можно закрепить через меню «Файл → Закреплённые файлы». Закреплённые файлы всегда доступны в списке, даже после перезапуска приложения.

История

Последние 50 открытых файлов сохраняются в истории. Доступ: «Файл → Недавние файлы».

05 Редактор

В основе лежит Monaco Editor — тот же движок, что используется в Visual Studio Code.

Возможности

  • Подсветка синтаксиса JSON
  • Автозакрытие скобок {}, [], ""
  • Нумерация строк
  • Сворачивание блоков (folding)
  • Мини-карта (minimap) справа
  • Поиск и замена (Ctrl+F / Ctrl+H)
  • Переход к строке (Ctrl+G)
  • Множественное выделение
  • Undo/Redo без ограничений
  • Масштабирование через Ctrl+колесо мыши
  • Автоформатирование при вставке

Валидация в реальном времени

При вводе невалидного JSON редактор автоматически подсветит ошибку красной волнистой линией и покажет описание при наведении.

06 Дерево JSON

Левая панель отображает структуру JSON в виде раскрывающегося дерева.

Функции

  • Раскрытие/сворачивание — клик по узлу или стрелке
  • Развернуть всё — кнопка в шапке панели
  • Свернуть всё — кнопка в шапке панели
  • Поиск — фильтрация узлов по тексту
  • Отображение типов — object, array, string, number, boolean, null
  • Счётчики — количество элементов в объектах и массивах

Дерево обновляется автоматически при изменении содержимого редактора.

07 Валидация

Быстрая проверка

Кнопка «Проверить» на toolbar или Инструменты → Проверить JSON. Показывает:

  • Статус валидности
  • Номер строки и столбца ошибки
  • Описание проблемы
  • Клик по ошибке — переход к проблемной строке

Результат показывает:

10 Инструменты

Генераторы

  • UUID v4 — генерация уникальных идентификаторов
  • Timestamp — текущее время в разных форматах (Unix, ISO, RFC2822)
  • Random Data — случайные пользовательские данные для тестирования
  • JSON Schema — генерация схемы по списку полей

Кодирование

  • Base64 — encode / decode
  • URL — encodeURIComponent / decodeURIComponent
  • Escape — JSON.escape / JSON.parse
  • Unicode — конвертер в \uXXXX формат

Вопросы и ответы

Часто задаваемые вопросы

Ответы на популярные вопросы о JSON Studio.

Нужен ли интернет для работы приложения?
Да, требуется подключение к интернету для загрузки веб-интерфейса с серверов Oris Platform. После загрузки интерфейс кэшируется браузером. Файлы обрабатываются локально и не отправляются на сервер (кроме операций сохранения настроек и истории).
Безопасно ли открывать конфиденциальные JSON-файлы?
Да. Содержимое файлов обрабатывается локально в вашем браузере и не передаётся на сервер. На сервер отправляются только метаданные (имя файла, размер) для истории недавних файлов. Сами данные JSON остаются на вашем устройстве.
Какой максимальный размер файла?
Максимальный размер файла — 100 MB. Для очень больших файлов (>10 MB) рекомендуется использовать портативную версию, так как она работает напрямую с файловой системой без ограничений браузера.
Почему не работает ассоциация файлов в portable-версии?
Portable-версия не вносит изменений в реестр Windows, поэтому ассоциация файлов невозможна. Для открытия файлов используйте drag & drop или меню «Файл → Открыть». Если нужна полная интеграция — используйте установщик.
Как обновить приложение?
Веб-интерфейс обновляется автоматически на сервере. Для обновления desktop-версии скачайте новый установщик с этой страницы и запустите его — он заменит старую версию, сохранив настройки.
Поддерживается ли macOS или Linux?
Desktop-версия доступна только для Windows 10/11. Однако веб-версия работает в любом современном браузере на любой операционной системе, включая macOS, Linux, iOS и Android.
Где хранятся настройки?
Настройки хранятся в Vercel KV (облачное хранилище) и привязаны к идентификатору пользователя. История недавних файлов также сохраняется в облаке. Локально в браузере хранится только кэш интерфейса.
Можно ли использовать JSON Studio коммерчески?
Да, JSON Studio бесплатен для личного и коммерческого использования. Никаких лицензионных ограничений нет.

О проекте

JSON Studio

Профессиональный редактор JSON для Windows 10/11, созданный командой Oris Platform. Приложение сочетает в себе мощь веб-технологий (Monaco Editor, Express, Vercel KV) с нативной интеграцией в операционную систему через Electron.

Проект разработан с акцентом на безопасность, производительность и удобство использования. Все данные обрабатываются локально, сервер используется только для синхронизации настроек и истории.
