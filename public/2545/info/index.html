О сервисе

Oris Optimizer — это простой и безопасный инструмент для уменьшения размера файлов без потери качества. Вся обработка выполняется прямо в вашем браузере: ваши данные никогда не покидают устройство.

Что умеет сервис

  • Оптимизация изображений: конвертация в формат WebP с сохранением визуального качества и удалением метаданных.
  • Минификация JSON: удаление лишних пробелов и форматирования без изменения структуры данных.
  • Сжатие текстовых файлов и кода: безопасная очистка комментариев и избыточных пробелов для JS, CSS, HTML, XML, SVG и TXT.
  • Мгновенная обратная связь: сравнение исходного и оптимизированного размера, процент экономии.
  • Конфиденциальность: ни один файл не передаётся на сервер. Обработка происходит локально с помощью стандартных API браузера.

Технологии

Сервис построен на чистых веб-технологиях: HTML, CSS и JavaScript. Никаких серверных фреймворков, облачных хранилищ или внешних обработчиков. Для работы с графикой используется HTML Canvas, для текста и JSON — встроенные парсеры браузера. Интерфейс адаптирован для мобильных и настольных устройств.

Безопасность и конфиденциальность

Мы не собираем никаких персональных данных, не используем трекеры и не загружаем ваши файлы. Сервис может сохранять технические сессионные cookie для стабильной работы, но они не служат для идентификации или слежки. Подробные положения изложены в документах:
