Политика конфиденциальности

Дата последнего обновления: 9 июня 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает, как сервис Oris Optimizer (далее — «Сервис») обращается с информацией, которую вы предоставляете при его использовании. Мы уделяем особое внимание защите ваших данных и стремимся быть максимально прозрачными.

2. Сбор информации

Oris Optimizer не собирает персональные данные пользователей. Мы не требуем регистрации, не запрашиваем имена, адреса электронной почты или иную идентифицирующую информацию. Сервис не использует файлы cookie для отслеживания поведения, профилирования или рекламных целей.

Технические данные, автоматически передаваемые браузером (IP-адрес, заголовки HTTP), не сохраняются и не анализируются, поскольку вся обработка происходит локально на вашем устройстве.

3. Обработка файлов

Файлы, которые вы загружаете для оптимизации, обрабатываются исключительно внутри вашего браузера с использованием стандартных Web API (Canvas, JSON, текстовые парсеры). Ни один файл не передаётся на удалённый сервер, не загружается в облако и не доступен третьим лицам.

После завершения сеанса оптимизированный файл остаётся только у вас; Сервис не хранит ни исходные, ни обработанные копии.

4. Использование файлов cookie

Сервис может использовать минимально необходимые технические cookie (например, для сохранения состояния интерфейса или сеанса), однако они не применяются для сбора статистики, идентификации пользователя или маркетинговых целей. Вы можете отключить cookie в настройках браузера без ущерба для основной функциональности.

5. Безопасность

Мы принимаем разумные технические меры для обеспечения безопасности кода Сервиса и предотвращения вредоносных модификаций. Тем не менее, мы рекомендуем вам всегда использовать актуальные версии браузеров и операционных систем, а также сохранять оригиналы важных файлов перед оптимизацией.

6. Сторонние сервисы

Oris Optimizer не интегрирует сторонние сервисы аналитики, рекламные сети или виджеты социальных сетей. Единственное внешнее подключение — шрифты Google Fonts, которые загружаются для обеспечения единого визуального стиля. Google может собирать агрегированную статистику запросов согласно своей политике конфиденциальности, но эти данные не связываются с вашим использованием Сервиса.

7. Изменения политики

Мы можем периодически обновлять настоящую Политику конфиденциальности. Новая редакция вступает в силу с момента публикации на этой странице. Мы рекомендуем регулярно проверять этот документ. Продолжение использования Сервиса после изменений означает ваше согласие с обновлённой редакцией.
