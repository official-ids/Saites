Oris Optimizer — бесплатный инструмент для уменьшения размера файлов без потери качества. Вся обработка выполняется локально в браузере: ваши файлы не загружаются на сервер и не покидают устройство. Json Studio
oris-flax.vercel.app/json-studio
JSON Studio — подробное описание продукта Общие сведения JSON Studio — это профессиональный редактор файлов формата JSON, разработанный командой Oris Platform для операционных систем Windows 10 и Windows 11. Приложение представляет собой гибридное решение, сочетающее в себе веб-интерфейс, работающий в любом современном браузере, и десктопное приложение на базе Electron с полной интеграцией в операционную систему. Продукт ориентирован на разработчиков, аналитиков данных, системных администраторов и всех специалистов, которым регулярно приходится работать с JSON-документами: от небольших конфигурационных файлов до крупных структур данных объёмом в десятки мегабайт. Архитектура JSON Studio построен по трёхуровневой архитектуре. Клиентская часть реализована на чистом HTML5, CSS3 и JavaScript без использования тяжёлых фреймворков. Это обеспечивает быструю загрузку и минимальное потребление ресурсов. В качестве редактора кода используется Monaco Editor версии 0.44.0 — тот же движок, что применяется в Visual Studio Code. Серверная часть работает на Node.js с фреймворком Express и развёрнута на платформе Vercel в виде Serverless Functions. Для хранения данных используется Vercel KV — Redis-совместимое облачное хранилище. Сервер отвечает за валидацию JSON, конвертацию между форматами, генерацию данных, управление настройками пользователей и хранение истории файлов. Десктопная оболочка построена на Electron версии 42.5.0 и по сути является обёрткой над веб-версией с добавлением нативных возможностей: локальная работа с файловой системой, ассоциация файлов, системное меню, кастомная шапка окна в стиле Windows 11. Возможности редактора Редактор Monaco предоставляет полный набор функций профессиональной IDE: Подсветка синтаксиса JSON с раскраской ключей, строковых значений, чисел, булевых значений и служебных символов в разные цвета. Цветовая схема адаптируется под выбранную тему оформления. Автоматическое закрытие скобок и кавычек. При вводе открывающей фигурной или квадратной скобки редактор автоматически добавляет закрывающую. То же самое происходит с кавычками. Нумерация строк слева от основной области редактирования. Номера обновляются в реальном времени при добавлении и удалении строк. Сворачивание блоков (folding). Рядом с номерами строк появляются маркеры, позволяющие свернуть любой объект или массив в одну строку для удобства навигации по крупным документам. Мини-карта (minimap) справа от редактора, показывающая уменьшенное представление всего документа для быстрой навигации. Поиск и замена с поддержкой регулярных выражений, учёта регистра и поиска по целым словам. Горячие клавиши Ctrl+F для поиска и Ctrl+H для замены. Переход к конкретной строке по номеру через сочетание Ctrl+G. Множественное выделение — возможность редактировать несколько мест в документе одновременно. Неограниченная история отмены и повтора действий через Ctrl+Z и Ctrl+Y. Масштабирование шрифта через сочетание Ctrl и прокрутки колеса мыши в диапазоне от 10 до 32 пунктов. Автоформатирование при вставке текста из буфера обмена. Валидация в реальном времени. При вводе невалидного JSON редактор немедленно подсвечивает проблемное место красной волнистой линией и показывает описание ошибки при наведении курсора. Дерево JSON Левая панель приложения отображает структуру открытого JSON-документа в виде интерактивного дерева. Каждый узел дерева соответствует ключу или элементу массива в документе. Функции дерева: Раскрытие и сворачивание узлов по клику. Рядом с каждым объектом или массивом отображается стрелка-индикатор состояния. Кнопки «Развернуть всё» и «Свернуть всё» в шапке панели для быстрого управления видимостью всех уровней вложенности. Поиск по дереву. Введённый в поле поиска текст фильтрует узлы, оставляя видимыми только те, что содержат искомую строку. Отображение типов данных. Рядом с каждым узлом указывается его тип: object, array, string, number, boolean или null. Счётчики элементов. Для объектов и массивов отображается количество дочерних элементов в виде небольшого бейджа. Автоматическое обновление. При любом изменении содержимого редактора дерево перестраивается с сохранением состояния раскрытия узлов. Валидация JSON Studio предлагает два уровня валидации. Быстрая проверка синтаксиса выполняется по нажатию кнопки «Проверить» на панели инструментов или через меню «Инструменты — Проверить JSON». Результат отображается в правой панели и включает: Статус валидности документа. При отсутствии ошибок показывается зелёный индикатор «JSON валиден». При наличии ошибок — список всех проблем. Точное указание позиции ошибки: номер строки и номер столбца, где обнаружена проблема. Описание ошибки на русском языке. Интерактивность: клик по ошибке в списке автоматически перемещает курсор редактора в проблемное место. Валидация по JSON Schema — расширенная проверка структуры документа на соответствие заданной схеме. Поддерживаются следующие ключи схемы: type — ожидаемый тип значения (object, array, string, number, boolean, null). required — массив обязательных полей объекта. properties — описание свойств объекта с рекурсивной валидацией. enum — список допустимых значений. minLength и maxLength — ограничения длины строки. pattern — регулярное выражение, которому должна соответствовать строка. minimum и maximum — ограничения числового значения. minItems и maxItems — ограничения размера массива. items — схема для валидации элементов массива. Результат валидации по схеме показывает все несоответствия с указанием пути к проблемному полю в JSON-структуре. Конвертация форматов JSON Studio поддерживает двустороннюю конвертацию между четырьмя форматами данных: JSON, XML, YAML и CSV. Конвертация выполняется через диалоговое окно, доступное по пункту меню «Инструменты — Конвертация». Пользователь выбирает исходный и целевой форматы, вставляет данные и получает результат, который можно скопировать или вставить в редактор. Особенности конвертеров: JSON в XML — объекты преобразуются во вложенные теги, массивы дублируют родительский тег, специальные символы экранируются. XML в JSON — теги преобразуются в ключи объектов, повторяющиеся теги автоматически группируются в массивы, текстовое содержимое автоматически приводится к соответствующему типу (число, булево значение, null или строка). JSON в YAML — с сохранением читаемой структуры, правильными отступами и экранированием многострочных строк. YAML в JSON — поддержка комментариев (игнорируются), вложенных структур и массивов. JSON в CSV — требует, чтобы исходный JSON был массивом объектов. Первый объект определяет заголовки столбцов, значения экранируются при наличии запятых, кавычек и переносов строк. CSV в JSON — первая строка интерпретируется как заголовки, последующие строки как значения. Автоматическое приведение типов для чисел и булевых значений. Все конвертеры реализованы на стороне сервера без использования внешних зависимостей. Инструменты Правая панель приложения содержит вкладку «Инструменты» с набором утилит для работы с данными. Генератор UUID v4. Создаёт уникальные идентификаторы в стандарте RFC 4122. Можно сгенерировать от 1 до 100 UUID за один запрос. Конвертер Timestamp. Показывает текущее время в нескольких форматах одновременно: миллисекундный timestamp, Unix-время в секундах, ISO 8601, локальное время в формате ru-RU, RFC 2822 и название часового пояса. Генератор случайных данных. Создаёт массив записей с полями: уникальный идентификатор, имя, возраст, email, флаг активности, числовой счётчик, дата создания и массив тегов. Полезно для тестирования API и заполнения баз данных. Генератор JSON Schema. Создаёт шаблон схемы по списку полей с правильными типами данных и ограничениями. Кодирование Base64 — преобразование текста в Base64 и обратно. Кодирование URL — encodeURIComponent и decodeURIComponent для работы с адресами. Escape/Unescape JSON — преобразование строки в JSON-представление с экранированием специальных символов и обратное преобразование. Unicode конвертер — преобразование символов в формат \uXXXX и обратно. Генератор хешей SHA-256 — вычисление контрольной суммы строки. Результаты всех инструментов можно вставить в текущий документ в редактор одним кликом. Система файлов JSON Studio предоставляет полноценную систему управления файлами. Открытие файлов возможно тремя способами: через меню «Файл — Открыть» или сочетание Ctrl+F, через проводник Windows с помощью пункта контекстного меню «Открыть с помощью JSON Studio» (только в десктопной версии), а также перетаскиванием файла в окно приложения (drag and drop). Сохранение выполняется по сочетанию Ctrl+S в текущий файл или через Ctrl+Shift+S с выбором нового пути. При сохранении автоматически создаётся резервная копия в облачном хранилище Vercel KV со сроком хранения 7 дней. Автосохранение каждые 30 секунд (интервал настраивается) для открытых файлов с путём. История недавних файлов — последние 50 открытых файлов сохраняются в облаке и доступны через меню «Файл — Недавние файлы». Закрепление файлов — важные файлы можно закрепить, и они всегда будут доступны в отдельном списке независимо от истории. Удаление файлов с очисткой всех связанных данных: записей в истории, резервных копий. Десктопная версия Десктопное приложение распространяется в двух вариантах: Установщик NSIS — полная установка с созданием ярлыков на рабочем столе и в меню «Пуск», регистрацией ассоциации файлов .json в реестре Windows и добавлением пункта «Открыть с помощью JSON Studio» в контекстное меню проводника. Portable-версия — один исполняемый файл, который можно запускать с любого носителя без установки. Не вносит изменений в систему. Особенности десктопной версии: Кастомная шапка окна в стиле Windows 11 с кнопками свернуть, развернуть и закрыть. Кнопка закрытия подсвечивается красным при наведении, как в стандартных окнах Windows. Нативные диалоги открытия и сохранения файлов через системные окна Windows. Обработка открытия файлов через ассоциации — при двойном клике по .json файлу он автоматически открывается в JSON Studio. Single-instance режим — если приложение уже запущено, повторный клик по файлу открывает его в существующем окне, а не запускает новую копию. Системное меню с пунктами «Файл», «Вид», «Справка» и стандартными сочетаниями клавиш. API Серверная часть предоставляет REST API, доступный по адресу /api/json_studio. Основные эндпоинты: GET /health — проверка работоспособности сервера с информацией об аптайме и использовании памяти. GET /files — список открытых файлов. POST /files/open — открытие файла с валидацией. POST /files/save — сохранение файла с созданием резервной копии. POST /files/save-as — сохранение под новым именем. DELETE /files/:path — удаление файла. POST /files/pin — закрепление файла. POST /validate — валидация JSON с указанием позиции ошибки. POST /format — форматирование с настраиваемыми отступами. POST /minify — минификация с расчётом процента сжатия. POST /sort — рекурсивная сортировка ключей по алфавиту. POST /convert — конвертация между JSON, XML, YAML и CSV. POST /compare — сравнение двух JSON-документов. POST /schema/validate — валидация по JSON Schema. GET /recent — история недавних файлов. GET и POST /settings — пользовательские настройки. POST /generate — генераторы UUID, timestamp, случайных данных, JSON Schema. POST /encode — инструменты кодирования. GET /stats — статистика использования системы. Все эндпоинты возвращают ответы в формате JSON с понятными кодами ошибок и сообщениями на русском языке. Технологии Frontend: HTML5, CSS3, Vanilla JavaScript, Monaco Editor 0.44.0. Backend: Node.js, Express, Vercel Serverless Functions. База данных: Vercel KV (Redis-совместимое хранилище). Десктоп: Electron 42.5.0, electron-builder 26.15.3. Хостинг: Vercel (Hobby Plan). CDN: Cloudflare для раздачи Monaco Editor и шрифтов. Сборщик десктопной версии: NSIS для создания установщика Windows. Системные требования Операционная система: Windows 10 версии 1809 или новее, Windows 11. Архитектура процессора: x64 (64-бит). Оперативная память: минимум 4 ГБ, рекомендуется 8 ГБ.
